# 3D viewer demonstration asset

Use Khronos glTF Sample Assets' **Corset** model to verify GLB loading and camera controls when integrating the 3D viewer. It is more representative of a fashion product than a generic object and has a permissive license:

- Model catalog and license/credits: <https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/Models-core.md>
- GLB: <https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/Corset/glTF-Binary/Corset.glb>
- The catalog lists Corset as CC0 1.0 Universal (credited to Microsoft for the model). Keep this source note with the asset if it is vendored into this project.

The model is stored locally as `corset.glb` and is only a demonstration model; do not show it as a model generated from a user's sketch. The catalog lists © 2017 UX3D, CC0 1.0 Universal, and credits Microsoft for the model.
